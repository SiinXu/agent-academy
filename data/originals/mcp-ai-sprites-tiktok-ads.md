Connect TikTok Ads Manager to Claude, ChatGPT, Cursor and any MCP client. See CPA and CTR for every ad, draft the next batch of hooks, and launch or change campaigns, with every change approved by you first.

## Quick start

1. **Connect TikTok Ads in Sprites.** Sign up at [sprites.ai](https://www.sprites.ai) and connect TikTok Ads once in the Sprites integrations menu. Start a trial from the Sprites site.
2. **Add the server to your client** with the URL `https://mcp.sprites.ai/mcp` (one endpoint for every client and every channel).
3. **Sign in.** Your client opens the Sprites consent screen. Sign in with the account your channels are connected to and approve.
4. **Ask.** Try: "With Sprites, which TikTok ads have the lowest CPA this month?"

## Setup by client

### Claude (claude.ai and Claude Desktop)

Works on Free (one custom connector), Pro, Max, Team and Enterprise.

1. Settings, then Customize, then Connectors. On Team and Enterprise an Owner adds it once under Organization settings, Connectors.
2. Click **+**, then **Add custom connector**. Name it `Sprites` and paste `https://mcp.sprites.ai/mcp`. Leave Advanced settings empty.
3. Click **Connect**, sign in to Sprites and approve.

Claude draws the Sprites approval card in the chat, so you can edit a budget or a headline in place and approve it.

### Claude Code

```bash
claude mcp add --transport http sprites https://mcp.sprites.ai/mcp
```

Then type `/mcp` inside Claude Code to finish the browser sign-in.

### ChatGPT

Plus, Pro, Business, Enterprise and Edu, on the web app. Not available on Free.

1. Settings, Security and login: turn on **Developer mode**. On Business and Enterprise an admin has to allow it first.
2. Settings, **Plugins** (formerly Connectors), then **+** to create an app.
3. Name `Sprites`, MCP server URL `https://mcp.sprites.ai/mcp`, Authentication **OAuth**. Tick the trust box and click Create.
4. Connect the app and sign in to Sprites.

### Cursor

`~/.cursor/mcp.json` (every project) or `.cursor/mcp.json` (one repo):

```json
{
  "mcpServers": {
    "sprites": {
      "url": "https://mcp.sprites.ai/mcp"
    }
  }
}
```

Cursor discovers the Sprites authorization server from the endpoint and opens a browser to sign in.

### Codex

```bash
codex mcp add sprites --url https://mcp.sprites.ai/mcp
codex mcp login sprites
```

Or by hand in `~/.codex/config.toml`:

```toml
[mcp_servers.sprites]
url = "https://mcp.sprites.ai/mcp"
auth = "oauth"
```

### VS Code and GitHub Copilot

`.vscode/mcp.json`. The top-level key is `servers`, not `mcpServers`, and a remote server needs `"type": "http"`:

```json
{
  "servers": {
    "sprites": {
      "type": "http",
      "url": "https://mcp.sprites.ai/mcp"
    }
  }
}
```

Run **Auth** above the entry, sign in, then switch Copilot Chat to **Agent** mode. Ask mode does not call MCP tools.

### Gemini CLI

`~/.gemini/settings.json`. Use `httpUrl`; a `url` entry is treated as SSE:

```json
{
  "mcpServers": {
    "sprites": {
      "httpUrl": "https://mcp.sprites.ai/mcp"
    }
  }
}
```

Restart the CLI; the first call opens the sign-in. Check with `gemini mcp list`.

## What it can read

- Campaigns, ad groups, ads and their status
- Spend, impressions, clicks, CTR, CPC, CPM, conversions and CPA
- Per-ad performance for every creative, Spark ads included
- Your uploaded videos, images and music

## What it can change (with your approval)

- Create campaigns, ad groups and ads
- Budgets, schedules, statuses and targeting
- New hooks and scripts, previewed before they ship

Every change arrives as an approval with the before and after. In Claude and ChatGPT it is a card you can edit
in place. In clients without cards, Sprites returns the change written out with a gate id, and applies it only
after you confirm (`approve_change`). Nothing is applied by the model on its own.

## Permissions

- **OAuth.** You connect TikTok once inside Sprites through the TikTok for Business authorization page, where you choose the advertiser accounts to share and approve the permissions the Sprites TikTok app requests.
- **No developer app.** You do not register a TikTok developer app or handle an app secret.
- **Account access.** Sprites acts on the advertiser accounts you authorized, with the access your TikTok user has on them.
- **Your AI client never holds a TikTok credential.** It holds a Sprites OAuth token bound to `https://mcp.sprites.ai/mcp`.

## Tools

The server exposes 20 tools to the model: 6 read tools and 14 write tools. Write tools that touch an ad account or a site only propose; nothing reaches either until you approve it. The tools that do the TikTok Ads work:

| Tool | What it does on TikTok Ads |
|---|---|
| `analyze` | Spend, CTR, CPC, conversions and CPA by campaign, ad group and ad. |
| `create_creative` | The next batch of hooks and scripts, drafted against the ads that convert. |
| `optimize` | Creative rotation and ad-group spend moved onto the winners. |
| `launch` | Campaign, ad groups and ads, built for TikTok's structure. |
| `research` | Hook ideas from what your audience says on Reddit, and competitor ads. |
| `change` | One budget, status or targeting edit. |
| `schedule_task` | A weekly creative report or a daily CPA check that runs inside Sprites. |

TikTok Ads requests use `channel: tiktok_ads`. Name another channel, or `all`, to compare.

Every task tool takes the same input: `goal` (the request written to stand on its own: Sprites sees only this
string, not the chat), `title` (a short label), `channel`, and `today` (the user's local date, so "last 30 days"
resolves correctly). Long tasks return a run id; `task_status` collects the result and `cancel_task` stops it.

## Official server vs this one

**TikTok for Business MCP server.** TikTok for Business hosts its own MCP server for the Marketing API, with no developer credentials needed. It comes flat, with about 400 tools, or layered, with about 40 core tools that load the rest on demand. It reads and writes campaigns, audiences, bidding, creative and catalogs on TikTok only.

| | Official / self-hosted | Sprites (this server) |
|---|---|---|
| Endpoint | Hosted by TikTok for Business | `https://mcp.sprites.ai/mcp` |
| Tools | About 40 core tools layered, or about 400 flat | Task tools: analyze, optimize, launch, change and more |
| Channels | TikTok | TikTok plus Meta, Google Ads, LinkedIn, Reddit, Microsoft, GA4, SEO and Shopify |
| Writes | Through the API as tools are called | Each change an approval card with before and after |
| New creative | Manages creative you have uploaded | Drafts hooks, scripts and concepts from what converts |

If you run TikTok alone and want its data and controls in a chat, TikTok's own server is the direct route; the layered version keeps the tool list small. Use Sprites when TikTok is one channel of several, when you want the next creative batch drafted, or when every change should wait for an approval.

## FAQ

**Is this a server I have to host?**
No. It is a hosted remote MCP server. Paste `https://mcp.sprites.ai/mcp` into your client and sign in.

**Can it upload video?**
It drafts hooks, scripts and concepts and proposes the ad. The video file itself is attached in the approval before anything publishes. Sprites writes creative; this tool does not generate video.

**Does it read Spark ads?**
Yes. Spark ads appear alongside in-feed creative with their own performance.

**What if TikTok is not connected yet?**
Sprites says so and hands back a link to connect it. The task resumes once the channel is live.

**Does it work for agencies with many TikTok accounts?**
Yes. The connector acts on the Sprites business you select, so you switch client with `choose_business` instead of re-adding the URL.

**Does it cover other channels?**
Yes. The same URL reaches Google Ads, Meta Ads, LinkedIn Ads, TikTok Ads, Reddit Ads, Microsoft Advertising,
Apple Ads, GA4, Search Console, Shopify, SEO and AI visibility, and Google Business Profile, for whatever is
connected in Sprites. See [ads-mcp-servers](https://github.com/sprites-ai/ads-mcp-servers).

**How much does it cost?**
The connector is included in every Sprites plan, and every plan starts with a short trial. See sprites.ai for current plans. TikTok Ads charges its own media
cost as usual.

**The client says it has no tools, or every call is unauthorized.**
Remove the server, re-add it with exactly `https://mcp.sprites.ai/mcp`, and sign in again. Grants are bound to that one URL.

**How do I revoke access?**
Disconnect the connector in your client, or remove the connection in Sprites. The next tool call fails closed.
