# SEO MCP Server

The Sprites MCP server connects Search Console and your CMS to any MCP client. This is the difference between an agent that drafts an article in the chat and one that researches the keyword, writes the post in your site's voice, links it internally and puts it in your CMS as a draft for approval.

## Quick start

1. **Connect Search Console and your CMS in Sprites.** Sign up at [sprites.ai](https://www.sprites.ai) and connect Google Search Console and your site (WordPress, Webflow, Shopify, Framer or a webhook) once in the Sprites integrations menu. Start a trial from the Sprites site.
2. **Add the server to your client** with the URL `https://mcp.sprites.ai/mcp` (one endpoint for every client and every channel).
3. **Sign in.** Your client opens the Sprites consent screen. Sign in with the account your channels are connected to and approve.
4. **Ask.** Try: "With Sprites, write a post on "programmatic SEO for SaaS" and put it in WordPress as a draft."

## Setup by client

### Claude (claude.ai and Claude Desktop)

Works on Free (one custom connector), Pro, Max, Team and Enterprise.

1. Settings, then Customize, then Connectors. On Team and Enterprise an Owner adds it once under Organization settings, Connectors.
2. Click **+**, then **Add custom connector**. Name it `Sprites` and paste `https://mcp.sprites.ai/mcp`. Leave Advanced settings empty.
3. Click **Connect**, sign in to Sprites and approve.

Claude draws the Sprites approval card in the chat, so you can edit a budget or a headline in place and approve it.

### Claude Code

```bash
claude mcp add --transport http sprites https://mcp.sprites.ai/mcp
```

Then type `/mcp` inside Claude Code to finish the browser sign-in.

### ChatGPT

Plus, Pro, Business, Enterprise and Edu, on the web app. Not available on Free.

1. Settings, Security and login: turn on **Developer mode**. On Business and Enterprise an admin has to allow it first.
2. Settings, **Plugins** (formerly Connectors), then **+** to create an app.
3. Name `Sprites`, MCP server URL `https://mcp.sprites.ai/mcp`, Authentication **OAuth**. Tick the trust box and click Create.
4. Connect the app and sign in to Sprites.

### Cursor

`~/.cursor/mcp.json` (every project) or `.cursor/mcp.json` (one repo):

```json
{
  "mcpServers": {
    "sprites": {
      "url": "https://mcp.sprites.ai/mcp"
    }
  }
}
```

Cursor discovers the Sprites authorization server from the endpoint and opens a browser to sign in.

### Codex

```bash
codex mcp add sprites --url https://mcp.sprites.ai/mcp
codex mcp login sprites
```

Or by hand in `~/.codex/config.toml`:

```toml
[mcp_servers.sprites]
url = "https://mcp.sprites.ai/mcp"
auth = "oauth"
```

### VS Code and GitHub Copilot

`.vscode/mcp.json`. The top-level key is `servers`, not `mcpServers`, and a remote server needs `"type": "http"`:

```json
{
  "servers": {
    "sprites": {
      "type": "http",
      "url": "https://mcp.sprites.ai/mcp"
    }
  }
}
```

Run **Auth** above the entry, sign in, then switch Copilot Chat to **Agent** mode. Ask mode does not call MCP tools.

### Gemini CLI

`~/.gemini/settings.json`. Use `httpUrl`; a `url` entry is treated as SSE:

```json
{
  "mcpServers": {
    "sprites": {
      "httpUrl": "https://mcp.sprites.ai/mcp"
    }
  }
}
```

Restart the CLI; the first call opens the sign-in. Check with `gemini mcp list`.

## What it can read

- Search Console queries, impressions, clicks and average position
- Your live site: structure, internal links, existing pages and voice
- Keyword volume, difficulty and SERP composition
- What currently ranks for the target query

## What it can change (with your approval)

- Blog posts, created as drafts in your CMS
- Landing and service pages, created or edited as a reviewable diff
- Titles, meta descriptions, focus keyphrases, headings and schema
- Publishing is always a separate, explicit approval

Every change arrives as an approval with the before and after. In Claude and ChatGPT it is a card you can edit
in place. In clients without cards, Sprites returns the change written out with a gate id, and applies it only
after you confirm (`approve_change`). Nothing is applied by the model on its own.

## Permissions

- **webmasters.** The full Search Console scope: search analytics, URL inspection and sitemaps.
- **webmasters.readonly.** The read-only scope a reporting setup uses. It cannot submit a sitemap.
- **Verified property.** Calls work only on a domain or URL-prefix property you are a verified owner or user of.
- **What Sprites asks for.** Google sign-in for the webmasters scope. Publishing goes through the CMS you connect separately.
- **What you skip.** You create no Google Cloud project or OAuth client for the Search Console API.
- **Your AI client never holds a platform credential.** It holds a Sprites OAuth token bound to `https://mcp.sprites.ai/mcp`.

## Tools

The server exposes 20 tools to the model: 6 read tools and 14 write tools. Write tools that touch an ad account or a site only propose; nothing reaches either until you approve it. The tools that do the SEO work:

| Tool | What it does on SEO |
|---|---|
| `write_seo_blog_post` | A researched post written onto your site as a draft. |
| `create_seo_page` | A landing or service page created or edited on the live site. |
| `analyze` | Search Console impressions, clicks, position and the pages that moved. |
| `research` | Keyword volume and difficulty by intent, and what already ranks. |

SEO requests use `channel: seo_web`. Name another channel, or `all`, to compare.

Every task tool takes the same input: `goal` (the request written to stand on its own: Sprites sees only this
string, not the chat), `title` (a short label), `channel`, and `today` (the user's local date, so "last 30 days"
resolves correctly). Long tasks return a run id; `task_status` collects the result and `cancel_task` stops it.

## FAQ

**Is this a server I have to host?**
No. It is a hosted remote MCP server. Paste `https://mcp.sprites.ai/mcp` into your client and sign in.

**How does it compare with other SEO MCP servers?**
There is no official SEO MCP server, and Google publishes none for Search Console. Every Search Console server is a third party wrapping the same public API. Community Search Console servers such as AminForou/mcp-gsc and ncosentino/google-search-console-mcp read queries, clicks and positions into a chat, on Google Cloud credentials you set up. Publishing needs a second server for your CMS, such as Automattic’s mcp-wordpress-remote. Sprites joins the two. It reads Search Console, keyword data and your live site, writes in the site’s voice with internal links into the pages that exist, and creates posts as drafts in your CMS, with publishing a separate approval.

**Which content management systems does it publish to?**
WordPress, Webflow, Shopify's blog, Framer, and any other CMS through a webhook. The CMS is connected once in Sprites; your agent never handles the credential.

**Will it publish without asking?**
No. Posts arrive as drafts and page edits arrive as diffs. Publishing is a separate approval, and a page edit shows you every block it would change.

**Is this not just ChatGPT writing an article?**
No, and the difference is the whole point. A chat draft is a document you then have to place. This researches the keyword against your Search Console data, writes in your site's voice, links into pages that exist, and lands in your CMS.

**Does it do keyword research too?**
Yes, with real volume and difficulty, clustered by intent, so the brief and the post come from the same pass.

**Can it edit an existing page rather than add one?**
Yes. Page edits are the safer half of this: you get a diff of the exact blocks that change and approve it before the live site moves.

**Does it cover other channels?**
Yes. The same URL reaches Google Ads, Meta Ads, LinkedIn Ads, TikTok Ads, Reddit Ads, Microsoft Advertising,
Apple Ads, GA4, Search Console, Shopify, SEO and AI visibility, and Google Business Profile, for whatever is
connected in Sprites. See [ads-mcp-servers](https://github.com/sprites-ai/ads-mcp-servers).

**How much does it cost?**
The connector is included in every Sprites plan, and every plan starts with a short trial. See sprites.ai for current plans. SEO is billed by its own vendor as usual.

**The client says it has no tools, or every call is unauthorized.**
Remove the server, re-add it with exactly `https://mcp.sprites.ai/mcp`, and sign in again. Grants are bound to that one URL.

**How do I revoke access?**
Disconnect the connector in your client, or remove the connection in Sprites. The next tool call fails closed.
