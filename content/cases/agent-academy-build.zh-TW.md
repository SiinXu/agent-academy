## 需求
Agent Academy 是一所給 agent 讀的學校：真實的 skill、prompt、MCP 伺服器和機器人範本，依職業整理，每一條都附原始連結和授權。首頁只有一件事要做：展示裡面有什麼，並交出一段可複製的 prompt。限制：10 種語言、淺色和深色、長連結永不溢出、所有卡片內距一致。

## 一直堅持的規則
- **中性色加一個強調色。** 每種風格只用一套中性色和一個強調色，文字對比度保持在 4.5:1 以上。
- **每個模組都來自 UI Hub。** 每個區塊寫明它移植自哪個 Hub 項目：ID、預覽圖和原始程式碼。移植有偏差時寫下原因。
- **由截圖決定。** 桌面和行動裝置、兩種主題的截圖檢查完溢出、截斷和內距不齊之前，什麼都不上線。

## 每一輪改了什麼
前幾輪先定外觀，再去找元件。結果是沒有用途的裝飾，被否決了。從第 4 輪起順序反過來：先為每個模組選定 Hub 元件，從原始碼移植，再用 token 套主題。這也是三種風格能共用同一套頁面結構的原因：變的只有 token、字型和招牌模組。

## 風格切換的原理
一段小腳本在首次繪製前設定 `<html data-skin>`，依序取 `?skin=`、已儲存的選擇，否則用 A。淺色和深色是獨立的開關。每種風格的 CSS 只作用於自己的外觀，所以切換時不載入新檔案，也不會閃爍。
