## ブリーフ
Agent Academy は、エージェントが読む学校です。実在のスキル、プロンプト、MCP サーバー、ボットテンプレートを職種別に整理し、すべてに出典リンクとライセンスを付けています。トップページの役割は 1 つ。中身を見せて、コピーできるプロンプトを 1 つ渡すこと。制約：10 言語、ライト／ダーク、長いリンクを絶対にはみ出させない、カードの余白はどこでも同じ。

## 守り続けたルール
- **ニュートラル＋アクセント 1 色。** どのスタイルもニュートラルのスケール 1 つとアクセント 1 色だけを使い、文字のコントラストは 4.5:1 以上。
- **すべてのモジュールは UI Hub から。** 各ブロックに移植元の Hub 項目（ID、プレビュー、元のコード）を明記。移植で変えた点があれば理由も書く。
- **スクリーンショットで決める。** デスクトップとモバイル、両テーマのスクリーンショットで、はみ出し・切れ・余白の不揃いを確認するまで公開しない。

## ラウンドごとに変わったこと
最初のラウンドは見た目を先に決め、コンポーネントを後から探しました。結果は役割のない装飾で、却下されました。ラウンド 4 から順序を逆にしました。モジュールごとに Hub コンポーネントを選び、ソースから移植し、最後にトークンでテーマを付ける。だから 3 つのスタイルが同じページ構造を共有できます。変わるのはトークン、フォント、特徴的なモジュールだけです。

## 切り替えの仕組み
小さなスクリプトが最初の描画より前に `<html data-skin>` を設定します。優先順は `?skin=`、保存された選択、そして A。ライト／ダークは別のトグルです。各スタイルの CSS はそのスキンにだけ効くので、切り替えても新しく読み込むものはなく、ちらつきもありません。
