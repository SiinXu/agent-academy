## 需求
Agent Academy 是一所给 agent 读的学校：真实的 skill、prompt、MCP 服务器和机器人模板，按职业整理，每一条都附原始链接和许可证。首页只有一件事要做：展示里面有什么，并交出一段可复制的 prompt。约束：10 种语言、浅色和深色、长链接永不溢出、所有卡片内边距一致。

## 一直坚持的规则
- **中性色加一个强调色。** 每种风格只用一套中性色和一个强调色，文字对比度保持在 4.5:1 以上。
- **每个模块都来自 UI Hub。** 每个区块写明它移植自哪个 Hub 条目：ID、预览图和原始代码。移植有偏差时写下原因。
- **由截图决定。** 桌面和移动端、两种主题的截图检查完溢出、截断和内边距不齐之前，什么都不上线。

## 每一轮改了什么
前几轮先定外观，再去找组件。结果是没有用途的装饰，被否定了。从第 4 轮起顺序反过来：先为每个模块选定 Hub 组件，从源码移植，再用 token 上主题。这也是三种风格能共用同一套页面结构的原因：变的只有 token、字体和标志性模块。

## 风格切换的原理
一段小脚本在首次绘制前设置 `<html data-skin>`，依次取 `?skin=`、已保存的选择，否则用 A。浅色和深色是单独的开关。每种风格的 CSS 只作用于自己的皮肤，所以切换时不加载新文件，也不会闪烁。
