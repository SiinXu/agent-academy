## 브리프
Agent Academy는 에이전트가 읽는 학교입니다. 실제 스킬, 프롬프트, MCP 서버, 봇 템플릿을 직업별로 정리했고, 모두 출처 링크와 라이선스가 붙어 있습니다. 홈페이지의 일은 하나입니다. 안에 무엇이 있는지 보여 주고, 복사할 프롬프트 하나를 건네는 것. 제약: 10개 언어, 라이트와 다크, 긴 링크는 절대 넘치지 않음, 카드 여백은 어디서나 같음.

## 끝까지 지킨 규칙
- **중립색에 강조색 하나.** 모든 스타일은 중립 스케일 하나와 강조색 하나만 쓰고, 글자 대비는 4.5:1 이상을 유지합니다.
- **모든 모듈은 UI Hub에서.** 각 블록에 이식한 Hub 항목(ID, 미리보기, 원본 코드)을 적습니다. 이식하면서 달라진 점이 있으면 이유도 적습니다.
- **스크린샷이 결정합니다.** 데스크톱과 모바일, 두 테마의 스크린샷에서 넘침, 잘림, 고르지 않은 여백을 확인하기 전에는 공개하지 않습니다.

## 라운드 사이에 바뀐 것
처음 라운드들은 모양을 먼저 정하고 컴포넌트를 나중에 찾았습니다. 결과는 역할 없는 장식이었고 거절당했습니다. 4라운드부터 순서를 뒤집었습니다. 모듈마다 Hub 컴포넌트를 고르고, 소스에서 이식한 뒤, 토큰으로 테마를 입힙니다. 그래서 세 스타일이 같은 페이지 구조를 나눠 쓸 수 있습니다. 바뀌는 것은 토큰, 글꼴, 대표 모듈뿐입니다.

## 전환이 작동하는 방식
작은 스크립트가 첫 렌더링 전에 `<html data-skin>`을 정합니다. 순서는 `?skin=`, 저장된 선택, 그다음 A입니다. 라이트와 다크는 별도의 토글입니다. 각 스타일의 CSS는 해당 스킨에만 적용되므로, 전환해도 새로 불러오는 것이 없고 깜빡이지 않습니다.
